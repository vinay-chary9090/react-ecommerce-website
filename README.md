# React E-Commerce Website

A frontend e-commerce website built using React.js.

### Features
- Product listings for Men, Women, and Kids
- Product details page
- Add-to-cart functionality
- Cart item count and item removal
- Login and signup UI

### Technologies
- React.js
- JavaScript
- HTML
- CSS
- React Router
- Vite

**Note:** Login and signup are UI only. Backend authentication is not implemented.
